
💱 ForexFusion

A beginner-friendly real-time currency converter built using HTML, CSS, JavaScript, and Fetch API.  
This project helps you understand how APIs work in real web applications while improving your frontend development skills.

✨ Features
- Live currency exchange rates
- Dynamic country flags
- Real-time API fetching using Fetch API
- Clean and responsive UI
- Beginner-friendly JavaScript logic

🚀 What You’ll Learn
- DOM Manipulation
- Async & Await
- Fetch API
- Event Handling
- Dynamic UI updates
- Working with APIs
- HTML/CSS project structuring

🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Fetch API

📌 Perfect project for beginners to practice JavaScript fundamentals and understand how real-world APIs are integrated into frontend applications.
